# 📱 تطبيق راصد تحويلات فودافون كاش وإنستاباي (Zei Transfers Listener)

تطبيق مخصص لهاتف التحويلات بنظام أندرويد (React Native) لمراقبة وقراءة رسائل الـ SMS وإشعارات الدفع (فودافون كاش، إنستاباي، أورانج كاش، اتصالات كاش، ورسائل البنوك) ومزامنتها فورياً مع موقع وسيرفر **Zei Perfumes**.

---

## 🌟 المميزات الرئيسية
1. **الاستماع اللحظي لرسائل الـ SMS (24/7):**
   - يعمل في الخلفية حتى عندما تكون الشاشة مغلقة.
   - يستخرج (المبلغ، اسم ومحفظة المزود، رقم المرسل، والرقم المرجعي) بدقة متناهية.
2. **المزامنة الفورية مع السيرفر (`api/fintech_sync.php`):**
   - مطابقة التحويلات مع أوردرات العملاء المعلقة وتأكيدها تلقائياً.
   - طابور الحفظ دون إنترنت (Offline Queue) وإعادة الإرسال فور عودة الاتصال.
3. **تصميم فاخر (Luxury Dark/Gold UI):**
   - إحصائيات يومية للمبالغ المستلمة وعدد العمليات.
   - سجل مباشر بالتحويلات مع علامات تأكيد الربط.
   - محاكي رسائل (Simulation Tool) لاختبار أي رسالة بنقرة زر.

---

## 🚀 طريقة تشغيل وتثبيت التطبيق على هاتف التحويلات

### متطلبات التشغيل:
- تثبيت Node.js
- تثبيت Android Studio أو بيئة Android SDK

### خطوات التشغيل:
1. افتح مجلد المشروع في التيرمينال:
   ```bash
   cd zei_fintech_listener
   ```

2. تثبيت الحزم والمكتبات:
   ```bash
   npm install
   ```

3. تشغيل التطبيق على الهاتف المتصل بالكمبيوتر عبر USB:
   ```bash
   npx react-native run-android
   ```

4. أو إنشاء ملف التثبيت المباشر (APK):
   ```bash
   cd android && ./gradlew assembleRelease
   ```
   سيتم إنشاء ملف الـ APK في المسار:
   `android/app/build/outputs/apk/release/app-release.apk`
